# New Testament — World English Bible (WEB)

All 27 books of the New Testament, one Markdown file per book, converted from the eBible.org USFM edition of the World English Bible (`eng-web_usfm.zip`, source files dated 22 Oct 2026).

- **License:** The World English Bible is in the public domain. "World English Bible" is a trademark of eBible.org. The conversion here changes only formatting (USFM → Markdown). The wording of the text is unchanged.
- **Format:** `## Chapter N` headings, verse numbers in bold, poetry as block quotes, and WEB translator footnotes (textual variants such as TR/NU/MT) as Markdown footnotes. Cross-reference markers and Strong's-number tags are removed.
- **Total verses:** 7958. Verses absent from modern critical texts (for example Matthew 17:21 and Mark 16:9–20) are kept as WEB prints them, and their footnotes are preserved.
